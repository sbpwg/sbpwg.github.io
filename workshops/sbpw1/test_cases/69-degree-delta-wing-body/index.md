# 69-Degree Delta Wing Body (2014)

Originally described as Model 4 in Lynn W. Hunton, Raymond M. Hicks, and Joel P. Mendoza, “Some Effects of Wing Planform on Sonic Boom,” NASA TN D-7160, 1972, [DOI:2060/19730006982](http://hdl.handle.net/2060/19730006982). See [NTRS Record](http://ntrs.nasa.gov/search.jsp?R=19730006982).

More details on the test case, condition, and data submission format will be provided at a later date.

See [Test Cases](../index.md) for instructions on submitting results. The HTTPS server contains the [geometry and required grids](https://lbpw-ftp.larc.nasa.gov/lbpw1/69deg-delta-wing/). See the README file on the HTTPS server for details.
